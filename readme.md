# Weather App

## *A simple weather web application, that lets you search for a city, and view its current weather information*

## **LIVE DEMO**: https://drish-weather-app.onrender.com

##Features
- Search by city
- current temperature
- Weather Condition
- Humidity percentage
- Time of sunset and Sunrise
- Wind speed
- Local date and Time
- Error handing for invalid cities
- responsive UI

## Technology Stack:
- HTML
- CSS
- JavaScript
- Python
- Flask
- OpenWeather API

## Deployed using Render
